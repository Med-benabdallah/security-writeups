## My Writeup Structure

Every writeup follows the same skeleton so you always know what to expect:

```
1. Overview          — what, where, impact (written last, reads first)
2. Background        — the vulnerability explained from scratch
3. Reconnaissance    — how I found the attack surface (the thinking, not just the clicks)
4. Finding the Vuln  — the moment of discovery
5. Exploitation      — step-by-step payload walkthrough
6. Impact            — real-world consequences
7. Mitigation        — how a developer should fix it (with code)
8. Lessons Learned   — personal reflection
```
